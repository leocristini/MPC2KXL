Drag sounds from the screen, or files from your computer, onto a pad. Drag pad to pad to swap. Hit a pad to hear and edit it.

Loading on the MPC: unzip, copy the files to the root of a FAT16 card or partition (SCSI2SD / CF mod), then LOAD on the MPC. With a Gotek, put them inside 1.44 MB floppy images; one image holds about 16 s of mono audio.

Programs: SAVE PGM gives a ZIP with NAME.PGM and a .SND for every sample on a pad (always .SND, using the keypad settings). Copy them all to the same folder, then load the .PGM on the MPC and choose to load its sounds too. Pads use the MPC's factory note layout (A01 = note 37).

WAV or .SND: the 2000XL reads both. WAV is the safest choice. .SND files use the native 42-byte header (name, level 100, tune 0, end point set to full length, loop off). Stereo .SND writes the left channel then the right, the way the MPC stores them.
